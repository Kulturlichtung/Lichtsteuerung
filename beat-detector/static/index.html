Beat-Erkennung

Die blaue Linie zeigt das Signal normalisiert in derselben Einheit wie Sensitivity (Streuungen über dem gleitenden Mittelwert). Die orange Linie ist die eingestellte Sensitivity selbst -- konstant, sie bewegt sich nur, wenn du sie ziehst oder das Zahlenfeld änderst. Ein Beat wird ausgelöst, sobald die blaue Linie die orange überschreitet. Ein roter Punkt markiert jeden tatsächlich erkannten Beat -- auch wenn die Linie selbst (nur ~10x/Sekunde gezeichnet) die kurze Spitze dazwischen nicht zeigt.

Auto-Stufen (Intensität)

Die 3 Linien lassen sich unabhängig ziehen oder per Zahlenfeld setzen. Werden zwei Linien beim Ziehen vertauscht, sortiert der Server sie automatisch wieder aufsteigend -- alle verbundenen Geräte zeigen danach denselben, sortierten Stand. Die grüne Linie zeigt normal den echten, verrauschten Pegel. Sobald aber ein Stufenwechsel intern tatsächlich "vorgemerkt" ist, bewegt sie sich stattdessen für die Dauer der Hold-Zeit gleichmäßig auf die nächste Schwelle zu -- kommt sie dort an, wechselt in genau diesem Moment auch wirklich die Stufe. Wird der Wechsel zwischendurch verworfen (Pegel fällt wieder), springt die Linie zurück auf den echten Pegel.
